# Integración Shopify - Odoo 19

Proyecto de integración entre Shopify y Odoo 19 utilizando Python, `httpx` y Pydantic.

## Requisitos previos

- Python 3.13+
- `uv` (administrador de paquetes)
- Docker Desktop (con soporte WSL 2 o Hyper-V)
